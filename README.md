# Шахматное Королевство

Весёлые шахматы для детей: уроки о том, как ходят фигуры, задачки и игра с добрыми соперниками.

Играть: https://ivantimurov13-design.github.io/chess-kingdom/

На iPad: открой ссылку в Safari → «Поделиться» → «На экран „Домой“». После первого запуска игра работает и без интернета.

Прогресс хранится только на этом устройстве. Перенести его на другое устройство можно в настройках игры: «Перенести прогресс».

Файлы здесь собираются автоматически — править их вручную не нужно.
